# 登录声明与策略包

LoginSpec 描述一次登录所需的页面操作、HTTP 请求、数据变换和会话写入。完整算子字段、默认值与错误码见 [`operators.md`](./operators.md)。

## 导入登录策略包

选项页 →「环境与账号」→「导入登录策略包…」→ 选择 `dt-login-config/v1` 格式的 JSON 文件。

- **仅存入策略库**（默认）：不新增环境，之后可在环境的「认证方式」中选择。
- **同时创建环境**：勾选包内环境，导入后关联到刚入库的策略；按提示填写所需变量。

策略包不包含账号绑定或 `secret` 变量。接收方需自行提供凭据；完整账号备份与策略包是不同用途，不要混淆。

## 公开仓库约定

本仓库只提供通用登录能力和文档，不分发任何特定内部系统的登录策略包、部署地址、凭据或密钥。请在本地或受控的私有渠道保存这类文件，**不要提交到公开仓库**。

`docs/login-specs/*.local.json` 已加入 `.gitignore`，可用于本地策略包；忽略规则不能撤销已提交文件的公开历史，提交前仍需检查文件内容。不要用真实密码、访问令牌或生产配置作为示例。
