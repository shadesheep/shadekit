# ShadeKit 登录配置文件契约

本文件描述两种既有 JSON 文件。文件名只用于识别，导入方按 JSON 内容判断格式，不依赖日期或随机后缀。两种文件与 `LoginSpec.version` 的版本规则见 [LoginSpec v2](login-spec-v2.md)。

## 1. 完整配置备份 `shadekit-config-YYYY-MM-DD.json`

### 外壳

顶层是配置对象：`__version` 表示完整配置迁移版本；其他顶层键是无 `devtools-` 前缀的工具 ID，例如 `account-switch`。当前扩展基线为 `__version: 3`，但这不是 LoginSpec 版本，也不表示文件已加密。

```json
{
  "__version": 3,
  "account-switch": {
    "accounts": [],
    "domains": {},
    "strategies": {}
  }
}
```

`account-switch` 包含环境、账号、角色、账号—环境绑定、策略库、变量和相关偏好。扩展备份可含其他工具配置；Desktop 只读取账号切换所需部分，可在摘要中说明忽略的其他工具。

### 明文秘密警告

**完整备份可以包含账号密码、环境默认密码、全局默认密码和 `secret` 变量的明文值。它不是加密备份。**

本地保险库把日常普通配置中的秘密替换为 `credentialRef` / secret 引用，并使用独立密文和密钥包装记录。只有用户明确执行完整备份导出时，受控运行层才把这些引用解析为可移植明文。保险库存储 key、密钥包装记录和本地密钥句柄不属于可移植备份内容。导出和导入确认前必须显示明文风险、影响环境/账号/策略/秘密数量及覆盖范围；导入时必须明确接受警告。

### 外壳拒绝与按环境禁用

- 无法解析的 JSON、未知或高于客户端支持范围的 `__version`、损坏的公共配置结构：拒绝整个文件，任何写入发生前失败。
- 可保留但含高 `LoginSpec.version`、未知/未实现算子或未知算法的环境：保留原始声明并禁用该环境；受支持的相邻环境照常导入。
- Desktop 不支持 `script` 时，完整备份中的相应环境可以禁用导入，其他环境不受影响。扩展支持 `script` 时按自己的能力检查处理。
- 禁用环境保留未知字段、vars、secret 值和账号绑定，支持状态只作为读取时派生元数据。
- 当前支持的 v2 声明仍须完整校验；结构损坏不是能力缺口，不能作为可执行环境导入。

### 预览与原子提交

解析、外壳校验、环境/账号/策略引用检查、冲突与覆盖计划、秘密引用准备、支持报告全部在内存中完成后才允许确认。预览和确认是两步，待提交明文只能留在受控运行层内存中。

提交时先建立恢复记录，再写秘密与配置，并通过同一读取路径逐项回读。任何写入或回读失败都恢复导入前的配置和密文，不留下半导入环境、半导入账号或悬空引用。普通配置、Content Script DTO、日志和诊断不能出现备份明文秘密。

## 2. 策略分享包 `dt-login-config-*.json`

### 外壳与内容

```json
{
  "format": "dt-login-config/v1",
  "specVersion": 2,
  "requiredVars": [{ "name": "tenant", "title": "租户" }],
  "environments": [
    {
      "name": "测试环境",
      "url": "https://test.example.com",
      "loginMethod": "generic",
      "spec": {
        "version": 2,
        "ops": [{ "op": "click", "target": "#submit" }],
        "success": [{ "page": { "type": "formGone" } }],
        "auth": { "mode": "page" }
      },
      "requiredVars": [{ "name": "tenant" }]
    }
  ]
}
```

- `format` 是文件外壳版本，只接受 `dt-login-config/v1`。`dt-login-config/v2` 等未知外壳拒绝整个文件。
- `specVersion` 是生成方声明能力版本。它高于当前客户端时，禁用受影响环境，不能误当作未知外壳。
- `requiredVars` 是用户需要填写的非秘密变量；包级和环境级变量都必须是相应 `spec.vars` 的子集。
- `environments[]` 携带环境名、URL、登录声明和变量信息，不携带账号、密码或账号绑定。接收方导入后自行添加或绑定账号。

### 包级非法内容

策略分享包用于分享可审查的非秘密声明：

- 任一环境含 `script`：**包级非法**，拒绝导入，不按单个环境禁用。
- 任一 `spec.vars[]` 含 `secret: true`，或 requiredVars 试图引入秘密变量：包级非法。
- requiredVars 未在声明 vars 中、公共结构损坏、无法保留必要字段：配置无效。
- 当前支持的 v2 声明必须通过全部结构及 R1–R7 校验。

### 按环境能力禁用

可保留环境中的高 `specVersion` / `spec.version`、未知/未实现算子、未知摘要或加密算法，只禁用相应环境。原始 spec 及未知字段在 JSON 值层面保留，不做迁移、模板改写或字段过滤。包级 `specVersion` 作为每个导入声明的本地来源元数据保存，执行和后续能力检查必须同时考虑它；导出时不能把它误写进原始 `LoginSpec`。

镜像到策略库的不支持声明会禁用所有绑定环境；以后客户端增加能力时从同一份原始声明重新检查，无需重新导入。策略包沿用既有 URL 冲突默认：无冲突项默认勾选，冲突项默认不勾选并选择 `create`，用户可显式选择 `overwrite`；覆盖影响必须在确认前展示。

## 3. 两种文件的共同安全边界

- 导入阶段不自动真实登录，不清 Cookie、不导航、不发登录 HTTP、不写会话。
- 不支持的环境在任何权限申请、导航、HTTP、会话写入或秘密发送之前阻断。
- 可禁用环境仍允许查看、导出、删除和管理非执行性账号绑定。
- 普通 Vue 页面和 Content Script 不读取已保存秘密；执行请求使用账号 ID / 环境 ID，由受控运行层重新校验并只解析本次所需秘密。
- 不新增第三种导入格式，不使用 `shadekit-backup/v1`，不提供主密码或加密备份入口。
